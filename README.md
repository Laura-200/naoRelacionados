## 📌 Sobre o projeto

Este projeto foi desenvolvido como atividade prática da disciplina de **Banco de Dados Não Relacional**, com o objetivo de compreender e aplicar os conceitos de armazenamento e gerenciamento de informações utilizando o MongoDB.

A aplicação consiste em uma API REST para gerenciamento de produtos de uma loja, permitindo realizar operações de cadastro, consulta, atualização e exclusão de registros.

O desenvolvimento utiliza JavaScript com Node.js, Express para criação das rotas e MongoDB como sistema de gerenciamento de banco de dados não relacional.

## 🧪 Testes da API

Para testar o funcionamento da aplicação, foi utilizado o **Thunder Client**, uma extensão do Visual Studio Code que permite realizar requisições HTTP diretamente no editor.

Por meio dele, foram testadas as rotas da API utilizando os métodos:

- POST — cadastro de produtos.
- GET — consulta de produtos.
- PUT — atualização de produtos.
- DELETE — exclusão de produtos.

Os dados foram armazenados e gerenciados no **MongoDB**, permitindo verificar o funcionamento das operações realizadas pela API.
